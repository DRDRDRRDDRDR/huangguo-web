数据源说明

  • 优先使用黄果官方 JSON 接口，HTML 抓取仅作兜底，响应中的 source 字段标明来源。
  • 封面为 AES-CBC 加密的原始二进制，由 /media 解密后返回。
  • m3u8 为 AES-128 加密切片，由 /raw 代理并重写分片与密钥地址。
  • 浏览器不支持原生 HLS，播放器库由 /hls.js 代理提供。
